# Knowledge

Short lessons in simple English, one topic per file. The app's Math School shows the same lessons (`app/learn/lessons.js`) and calculates its examples live with the engine.

Rules:
- Every number comes from the odds engine or a named source.
- Numbers not checked yet are marked **"to validate"**.
- Shortcuts (like the rule of 2 and 4) are marked as shortcuts.

Files: `positions.md`, `pot-odds.md`, `outs.md`, `equity.md`, `stack-sizes.md`, `push-fold.md`, `bubble-icm.md`.
