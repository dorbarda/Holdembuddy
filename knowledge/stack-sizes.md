# Stack size and M-ratio

- Big blinds = chips ÷ big blind.
- M-ratio = chips ÷ (small blind + big blind + all antes): how many rounds you survive without playing.
- Check it each time the blinds go up.

| Example | BB | M-ratio |
|---|---|---|
| 3,000 chips, 100/200, ante 25, 9 players | 15.0 | 5.7 |
| 3,000 chips, 100/200, big blind ante 200 | 15.0 | 6.0 |

Numbers from `node app/engine/cli.js stack`.
